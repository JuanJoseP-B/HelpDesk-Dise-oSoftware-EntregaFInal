# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-03

### Added
- Initial release of the HelpDesk API.
- Hexagonal Architecture implementation.
- Domain-Driven Design (DDD) patterns.
- JWT Authentication and Authorization.
- Incident lifecycle management (Open -> Assigned -> In Progress -> Resolved -> Closed).
- SLA Monitoring and violating notifications.
- Role-based access control (CLIENTE, TECNICO, ADMINISTRADOR).
- Email notifications via SMTP.
- Automated tests (Unitary and Integration).
- Docker configuration.
- Postman Collection.
